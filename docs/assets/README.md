# Assets

`mark.png` is the repository mark the README displays at 96×96.
`mark-source.png` is the card it is cut from: `swarea-cyan-deep-0f6b7d`,
from the `ground-f7f7f6` set.

The shape follows
[the organization's mark rule](https://github.com/swarea/.github/blob/main/docs/repository-mark.md):
512 × 512, ground `#f7f7f6`, and a 75px corner radius. The colour is
`make-mark.html`'s draw of this card. The corner's alpha channel is identical
to the other swarea marks, which is the check the rule asks for.
