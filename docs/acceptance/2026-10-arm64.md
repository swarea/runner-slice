- **Registration and removal tokens** were obtained and entered by the
  owner. They travelled through a pipe into `ACTIONS_RUNNER_INPUT_TOKEN`, and

## Defects found on the real host, and fixed

Each fix landed with a drill case that fails without it.

1. **The release archive unpacked group-writable**, and root's preflight
   refused it (#16).
2. **`systemctl show` prints `RestrictNamespaces=yes`, not an empty value.**
   A correct host would have failed its own check (#17).
3. **The printed registration used `--replace`**, which silently takes over
   another host's runner of the same name (#17).
4. **`config.sh` checks its libraries by `./bin` paths before it changes
   directory.** Run from elsewhere, the check passed vacuously, with `ldd: …
   No such file` (#17, `env -C`; actions/runner #945 and #4460).
5. **`config.sh remove` rejects `--unattended`** (#17).
